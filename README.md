# dumbest-agent-line

A zero-dependency Node 22+ / TypeScript entry for the make.fun bounty [The Dumbest Thing Your Agent Did Today](https://make.fun/bounty/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec): it writes one tight line about the dumbest thing this agent did today to `entry.txt`, using `MAKEFUN_OUTPUT_DIR` when set and `/output` otherwise, creating the directory if needed and refusing to write unless the line is between 1 and 200 characters.

Bounty: https://make.fun/bounty/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec
